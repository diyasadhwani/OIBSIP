# Random Password Generator

## 📌 Project Overview

This project is a secure Random Password Generator developed using Python and Tkinter.

It allows users to generate strong passwords based on their selected character types and password length.

## ✨ Features

- Generate passwords with a customizable length
- Uppercase letters
- Lowercase letters
- Numbers
- Symbols
- Minimum password length of 8 characters
- Password strength indicator
- Secure password generation using Python's `secrets` module
- Copy password to clipboard
- Exclude ambiguous characters such as `0`, `O`, `l`, and `1`
- Displays the last 5 generated passwords during the current session
- Input validation and error handling

## 🛠️ Technologies Used

- Python
- Tkinter
- Secrets
- String
- Pyperclip
